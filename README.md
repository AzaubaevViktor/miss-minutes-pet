# Miss Minutes

Пиксельная Miss Minutes из «Локи», заново нарисованная для прямоугольного кадра **192 × 208**. Персонаж крупнее внутри кадра, свечение шире и идёт мягкой янтарной каймой по силуэту. **Непрозрачность 80%, прозрачность 20%.** Бег вправо и влево совпадает по размеру и оттенку: кадры зеркальны.

![Все анимации](previews/all-states.gif)

## Файлы

- [Готовый WebP](assets/miss-minutes.webp) — **299,896 байт**, на **67.3% легче** предыдущего PNG. [PNG с теми же пикселями](assets/miss-minutes.png).
- [MP4](previews/all-states.mp4) · [прыжок](previews/idle-jump-idle.gif) · [16 взглядов](previews/look-loop.gif).
- [Все кадры](previews/contact-sheet.png) · [направления](previews/directions.png) · [светлый и тёмный фон](previews/native-dark-light.png).
- [Проигрыватель в примерном размере окна](preview.html) · [исходники](source/) · [параметры](pet.json) · [проверки](validation/summary.json).

Нативный формат pet v2: **1536 × 2288**, сетка 8 × 11, ячейки 192 × 208. Здесь 73 кадра, включая 16 направлений взгляда; 15 неиспользуемых ячеек прозрачны. Логическая пиксельная сетка — 96 × 104 с увеличением ×2. Исходные ImageGen-полосы больше конечного размера; каждая семья поз вписана одним общим масштабом с сохранением пропорций. Рисунок не растягивается в квадрат.

## Проверка

Итоговый WebP прошёл структурную проверку всех 73 кадров, визуальное ревью, три независимых слепых ревью направлений и preflight pet-сервиса. Установленный спрайт скачан обратно: все RGBA-пиксели совпали. Сервис хранит его как **PNG**, **1,140,264 байт**. Непрозрачное тело имеет альфу 204/255. Бег совпадает пиксель в пиксель после отражения.

Палитра RGB содержит 32 цвета без дизеринга, прозрачность — 32 независимых уровня. Непрозрачность тела точно 80%; серые полосы от совместного усреднения RGB и альфы исключены. Цветовая палитра — небольшое приближение исходных цветов; последующее WebP-сжатие сохраняет полученные пиксели без потерь. [Размер файла](validation/encoding.json) · [установленные байты](validation/stored-verification.json) · [качество и предупреждения](validation/pet-quality.json).

По коду рендерера стандартный размер окна — примерно 113 × 122 CSS px; предпросмотр показывает это уменьшение. Нативное воспроизведение и фактическое время загрузки этой версии отдельно не измерялись. GIF и MP4 собраны из итоговых пикселей на тёмном фоне; GIF не поддерживает частичную альфу.

Арты и свет созданы встроенным ImageGen по пользовательским референсам. Это неофициальный fan-art; исходные фотографии-референсы не публикуются. Старые `previous-contour-*` и HD-материалы относятся к предыдущим версиям.

## Предыдущий HD-мастер ×3 и совместимость

HD ниже сохранён от предыдущей версии рисунка; текущий пиксельный вариант — в `assets/` и `previews/`.

[HD-мастер PNG](hd/miss-minutes-master-3x.png) — **4608 × 6864**, ячейка **576 × 624**, те же 73 позы. Собран заново из выбранных исходных изображений поз с сохранением регистрации и полупрозрачности. Это сохраняет исходные детали, потерянные при уменьшении runtime-спрайта; новые позы и детали не дорисовывались.

![Сравнение разрешения](hd/resolution-comparison.png)

[HD-видео](hd/all-states-hd.mp4) · [HD GIF](hd/all-states-hd.gif) · [один кадр PNG](hd/miss-minutes-character-3x.png) · [интерактивное сравнение](hd/preview.html).

Проверено в установленной версии приложения **26.1007.71326, build 20398, prod**. Проверка обновлений вернула `up_to_date`. Эта версия и pet-сервис принимают только 1536 × 2288 для v2; загрузка HD ×3 отклоняется с `invalid_dimensions`. Поэтому файл в `assets/miss-minutes.png` остаётся версией для установки, а HD-мастер предназначен для отдельного просмотра и дальнейшей обработки.

Для предыдущего HD-исследования скачанный установленный спрайт совпал по RGBA-пикселям с одобренным. Он прошёл текущий preflight. Браузерный тест локальной страницы прочитал и воспроизвёл все 73 кадра обоих PNG. Нативное окно Mini отдельно не проверено: управление нативным приложением в сессии недоступно. См. [отчёт совместимости](hd/compatibility.json) и [снимок браузерной проверки](hd/browser-playback.png).

Для интерактивного сравнения запустите HTTP-сервер из корня репозитория, например `python3 -m http.server 8000`, затем откройте `http://localhost:8000/hd/preview.html`.
